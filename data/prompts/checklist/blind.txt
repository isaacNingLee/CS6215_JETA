CWE's description: "The product uses external input to construct a pathname that is intended to identify a file or directory that is located underneath a restricted parent directory, but the product does not properly neutralize special elements within the pathname that can cause the pathname to resolve to a location that is outside of the restricted directory."

The checklist will be used on Java code that a taint analysis reported as a possible path traversal. For each reported method, a reviewer reads the method, the fields and constructors of its class, and the methods of the same class that it calls, and answers each question with yes or no only. The reviewer cannot explain, reason at length or ask for more code. The checklist decides whether the method is protected against path traversal.

Write the checklist as safe patterns: the ways Java code can prevent path traversal. Each pattern lists conditions, and the pattern applies only when every one of its conditions is answered yes. Write each condition as one yes/no question about the method under review that can be answered from that code, where yes means the code shows that part of the protection. Name the Java APIs to look for. Include only patterns that are correct protections, not ones that still leave a traversal possible.
